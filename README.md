# Employee Management System

## Project Overview

The Employee Management System is a JDBC-based web application developed using Java, JSP, Servlets, Maven, and MySQL. It allows users to register and log in and provides functionality to manage employee records.

## Technologies Used

- Java
- JSP (JavaServer Pages)
- Java Servlets
- JDBC
- Maven
- MySQL
- HTML and CSS

## Features

- User Registration and Login
- Employee Record Management
- Create, Read, Update, and Delete (CRUD) Operations
- Client-Side and Server-Side Validation
- MySQL Database Connectivity
- DAA Searching Algorithm Implementation

## Project Structure

- `pom.xml` – Maven project configuration
- `Employee.java` – Employee model
- `DBConnection.java` – Database connectivity
- `AuthServlet.java` – User authentication
- `EmployeeServlet.java` – Employee operations
- `SearchAlgorithms.java` – Searching algorithm implementation
- JSP files – User interface pages

## Setup Instructions

1. Install Java, Eclipse IDE, Maven, and MySQL.
2. Clone or download this repository.
3. Import the project into Eclipse as a Maven project.
4. Create the required MySQL database and tables.
5. Configure the database connection in `DBConnection.java`.
6. Run the application on a compatible servlet container, such as Apache Tomcat.
